# Y-COM

Y-COM is the Universal Human-AI Interaction Language of yOS.

Canonical boundary:

```text
Universal Input Layer = where/how signal enters
Y-COM               = what interaction means
Cognition/Routing    = what system decides
MTP                  = machine message transport protocol
BUS                  = runtime exchange fabric
```

Y-COM is bidirectional and modality-independent. V0.1 is intentionally small, deterministic, and evolutionary.
